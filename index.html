Every draw is one sha256(preimage) as a big-endian u256, reduced over the numbers still in the drum — so a repeat is reconsidered rather than drawn twice. The preimage is the compact JSON of {input, draw, drawn, big_c}: the round's public data (game, round, limits, pot, every bet) from get_roll_input, the index of this draw, the numbers already out, and big_c, the MPC network's derived key for (contract, path) — path round-N for game 0 and game-G-round-N otherwise, plus -draw-D from the second draw on — pairing-verified on-chain before the casino sees it. Single-outcome games settle on the first draw; bingo keeps drawing until a card is full. The check mark means this page recomputed every number of the round.
