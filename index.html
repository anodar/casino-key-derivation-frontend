How a draw is derived
big_c
The MPC network's derived key for (contract, path): the casino asks for it publicly verifiable with an identity app key, so it comes back in the clear and e(big_c, G2) = e(H(mpk ‖ app_id), mpk) holds for the key itself. The MPC contract checks that before returning it; this page checks it again. One per round.
path
round-N for game 0, game-G-round-N otherwise.
input
The round's public data from get_roll_input: game, round, limits, pot, every bet.
draw, drawn
This draw's index and the numbers already out — what gives each number a preimage of its own.
reduce
Over the numbers still in the drum, so a repeat is reconsidered rather than drawn twice. One number decides a single-outcome game; bingo draws until a card fills.
✓
Green: the key passed the pairing check against the MPC network's public key and every number of the round recomputed here, from the contract's own inputs. Amber: the numbers recomputed but the pairing library did not load.
