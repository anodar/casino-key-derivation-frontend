How a draw is derived
big_c
The MPC network's derived key for (contract, path), pairing-verified on-chain before the casino sees it. One per round.
path
round-N for game 0, game-G-round-N otherwise.
input
The round's public data from get_roll_input: game, round, limits, pot, every bet.
draw, drawn
This draw's index and the numbers already out — what gives each number a preimage of its own.
reduce
Over the numbers still in the drum, so a repeat is reconsidered rather than drawn twice. One number decides a single-outcome game; bingo draws until a card fills.
✓
Every number of the round recomputed here, from the contract's own inputs.
